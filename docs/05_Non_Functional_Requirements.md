# Non-Functional Requirements

## Localization (Internationalization)

### Supported Languages

- English (Default)
- Telugu

### Future Languages

- Hindi
- Tamil
- Kannada
- Malayalam

### Requirements

- Users can switch language at any time.
- Language preference is saved in the user profile.
- If not logged in, preference is stored locally.
- Language change should not require app restart.
- All UI text must come from localization resources.
- Currency, dates, and number formats should follow the selected locale where applicable.
- Responsive UI
- 99.9% availability
- JWT security
- Encrypted Aadhaar
- Audit logs
- Localization
- Monitoring
- CI/CD
