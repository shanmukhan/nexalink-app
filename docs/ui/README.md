# NexaLink UI/UX Documentation

This folder documents the Customer Mobile App UI based on the supplied wireframes and recommended improvements.

## Design Principles
- Minimal and modern
- Consistent 8pt spacing system
- Accessible (WCAG AA)
- Material 3
- Dark mode ready
- Responsive for phones and tablets

## Primary Navigation
Home • Shop • Team • Wallet • Profile

## Improvements over supplied design
- Replace password login with OTP-first authentication
- Add biometric login
- Add dark mode
- Better empty/loading/error states
- Universal search
- Pull-to-refresh
- Accessibility support
- Consistent status chips
- Skeleton loaders
