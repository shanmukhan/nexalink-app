# UX Recommendations

## Authentication
Use OTP instead of passwords.

## Navigation
Floating search.
Sticky bottom navigation.

## Product
Show cashback and referral benefits above the fold.

## Referral
Use interactive tree with filters and search.

## Wallet
Use ledger timeline rather than only balance.

## Accessibility
Support font scaling, screen readers and high contrast.

## Empty States
Every page should have meaningful illustrations and actions.

## Future
- AI recommendations
- Voice search
- Regional language support
- Offline mode
