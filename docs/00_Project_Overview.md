# NexaLink Platform - Project Overview

## Executive Summary
NexaLink is a scalable product distribution and referral platform. The MVP starts with a single TV product and evolves into a multi-category marketplace.

## Objectives
- Sell products through distributors
- Referral-based customer acquisition
- Wallet cashback
- Inventory and order management
- Customer, Distributor and Admin applications

## Applications
- Flutter Customer App (Android/iOS)
- Flutter Distributor Portal
- Flutter Admin Portal
- Spring Boot Backend
- PostgreSQL Database

## Initial Scope
- Single product
- Three referral limit
- Wallet cashback
- Warranty
- Reports
