# NexaLink AI Development Rules

Always follow Clean Architecture.

Use Feature First architecture.

Use Riverpod.

Use GoRouter.

Use Dio.

Use Freezed.

Use Json Serializable.

Never duplicate code.

Never hardcode colors.

Never hardcode strings.

Use localization.

Use Material 3.

Target Android, iOS and Web.

Responsive layouts.

Dark mode supported.

Accessibility first.

Every feature must include

- UI
- Domain
- Repository
- Data source
- Models
- Tests

Always ask before changing architecture.
